SecureQA · QA + Security
Python · Playwright · pytest · OWASP Python · Playwright · pytest · OWASP

Güvenlik odaklı test otomasyonu Security-focused test automation

SecureQA, bir QA otomasyon mühendisinin güvenlik bilgisini otomasyona taşıdığı bir portföy projesidir: güvenli yazılmış SecureShop demo mağazası, OWASP Juice Shop'a karşı 42 challenge, yeniden kullanılabilir güvenlik çerçevesi ve tarayıcıda gerçek Python çalıştıran interaktif rehber. SecureQA is a portfolio project that brings security testing into a QA automation workflow: a securely built SecureShop demo, 42 attacks against OWASP Juice Shop, a reusable security framework, and an interactive guide that runs real Python in your browser.

🛒 SecureShop

Güvenli yazılmış, TR/EN, karanlık/aydınlık temalı Flask demo mağazası — fonksiyonel testlerin ve savunma kontrollerinin hedefi. CSP, güvenlik başlıkları, HttpOnly/SameSite çerezler, CSRF, parametreli SQL.

A securely built, bilingual, dark/light Flask demo shop — the target for functional tests and defensive regression checks: CSP and security headers, HttpOnly/SameSite cookies, CSRF, parameterized SQL.

Page Object Model, reusable security checks, findings mapped to OWASP Top 10 2021 + CWE, and a self-contained bilingual HTML dashboard (inline SVG charts, filters).

🧃 OWASP Juice Shop

Bilerek açıklı eğitim uygulamasına karşı 42 challenge: SQLi, XSS, IDOR, yetki aşımı ve daha fazlası — her biri /api/Challenges ile doğrulanır ve CVSS 3.1 ile puanlanır.

42 challenges against the intentionally vulnerable training app: SQLi, XSS, IDOR, broken access control and more — each verified via /api/Challenges and scored with CVSS 3.1.
